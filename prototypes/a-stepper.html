Recap 1 of 3 · note 0

Knobs and residuals

A linear model predicts a label from the features using three knobs (weights) \(\theta_0, \theta_1, \theta_2\). The residual of sample \(i\) is its prediction minus its true label:

\[r_i = \theta_0\cdot 1 + \theta_1 x^{(i)}_1 + \theta_2 x^{(i)}_2 - y_i\]

\(x^{(i)}_1\) = feature 1 of sample \(i\). The \((i)\) up top is the row number, not a power.

Recap 2 of 3 · note 1

All residuals at once

Each sample becomes a row \((1, x_1, x_2)\) of the matrix \(X\). The first column of ones is the 1 that multiplies \(\theta_0\). Then \(X\theta\) is all predictions and \(r = X\theta - y\) is all residuals. 2025-C's table, with \(\theta = (1, -2, 3)\):

\[X = \begin{bmatrix}1&-1&1\\1&-2&0\\1&1&3\\1&0&1\end{bmatrix}\] \[r = X\theta - y = \begin{bmatrix}6\\5\\8\\4\end{bmatrix} - \begin{bmatrix}6\\4\\5\\1\end{bmatrix} = \begin{bmatrix}0\\1\\3\\3\end{bmatrix}\]
Recap 3 of 3 · notes 2–3

The loss: one number

Square each residual and add them up, so errors can't cancel. 2025-C's loss (LASSO) also adds a penalty: \(\lambda\) times the size of every knob, including \(\theta_0\).

\[J_\lambda(\theta) = \sum_{i=1}^{n} r_i^2 \;+\; \lambda\big(|\theta_0| + |\theta_1| + |\theta_2|\big)\]

For our residuals the first part is \(0^2 + 1^2 + 3^2 + 3^2 = 0 + 1 + 9 + 9 = 19\).

Check · predict, then reveal

Prediction and residual of sample 3

Row 3 of \(X\) is \((1, 1, 3)\), \(\theta = (1, -2, 3)\) and \(y_3 = 5\). What is prediction 3, and what is \(r_3\)?

Say it or write it first. (This is a sub-step of 2025-C Q1.3.)

\[\begin{aligned}&(1, 1, 3)\cdot(1, -2, 3)\\ &= 1\cdot 1 + 1\cdot(-2) + 3\cdot 3\\ &= 1 - 2 + 9 = 8\end{aligned}\] \[r_3 = 8 - 5 = 3\]

That's entry 3 of \(r = (0, 1, 3, 3)\).

The gradient · note 5

The picture: a landscape

Think of \(J\) as a landscape. Your position is the knob setting \(\theta\); the height there is the loss \(J(\theta)\). Training = finding the lowest point. You can't see the whole landscape, but where you stand you can feel which way the ground slopes. The gradient is that slope.

The gradient · note 5, step 1

One knob: the partial derivative

Turn only knob \(\theta_1\) up a tiny bit and hold the others still: how fast does \(J\) change? That is the partial derivative \(\partial J / \partial\theta_1\). Compute it like an ordinary derivative, treating the other knobs as constants.

Positive: turning \(\theta_1\) up makes the loss worse. Negative: turning \(\theta_1\) up makes it better.

The gradient · note 5, step 2

All knobs: the gradient vector

Stack the partial derivatives into one vector, one entry per knob. It points uphill (where the loss grows fastest), so \(-\nabla J\) points downhill.

\[\nabla J = \left(\frac{\partial J}{\partial\theta_0},\ \frac{\partial J}{\partial\theta_1},\ \frac{\partial J}{\partial\theta_2}\right)\]

So we need \(\partial J/\partial\theta_j\) for one general knob \(j\). The next screens build it.

Check · recall

What does a positive entry mean?

Suppose \(\partial J/\partial\theta_2\) is positive. What happens to the loss if you turn \(\theta_2\) up? So which way should you turn \(\theta_2\)?

Turning \(\theta_2\) up makes the loss bigger (worse). So turn \(\theta_2\) down. That is what "\(-\nabla J\) points downhill" means.

Building it · 1 of 4

Derivative of one residual

In \(r_i = \theta_0\cdot 1 + \theta_1 x^{(i)}_1 + \theta_2 x^{(i)}_2 - y_i\), only the term \(\theta_j x^{(i)}_j\) contains \(\theta_j\). Everything else is a constant, with derivative 0. Call the 1 in front of \(\theta_0\) "feature 0": \(x^{(i)}_0 = 1\).

\[\frac{\partial r_i}{\partial\theta_j} = x^{(i)}_j\]

Official solutions quote this as "seen in class". You may too.

Building it · 2 of 4

One sample's loss: chain rule

Sample \(i\) contributes \(r_i^2\). Chain rule: the outer derivative \(2r_i\) times the inner derivative \(\partial r_i/\partial\theta_j\), which the last screen gave.

\[\frac{\partial}{\partial\theta_j}\, r_i^2 = 2r_i\cdot\frac{\partial r_i}{\partial\theta_j} = 2r_i\, x^{(i)}_j\]
Building it · 3 of 4

Add over the samples

The derivative of a sum is the sum of the derivatives. Then pull the constant 2 out in front.

\[\frac{\partial}{\partial\theta_j}\sum_{i=1}^{n} r_i^2 = \sum_{i=1}^{n} 2r_i\, x^{(i)}_j = 2\sum_{i=1}^{n} x^{(i)}_j\, r_i\]
Building it · 4 of 4

All knobs at once: \(X^\top\)

\(x^{(1)}_j, \dots, x^{(n)}_j\) is feature \(j\) of every sample: column \(j\) of \(X\). So \(\sum_i x^{(i)}_j r_i\) = (column \(j\) of \(X\)) \(\cdot\, r\). \(X^\top\) turns columns into rows, so \(X^\top r\) does all these dot products at once:

\[\nabla \sum_{i} r_i^2 = 2X^\top r = 2X^\top(X\theta - y)\]

Size check: \(X^\top\) is \(3\times 4\), \(r\) is \(4\times 1\), so 3 entries, one per knob. Not \(X(X\theta - y)\).

Check · a sub-step of 2025-C Q1.3

Column 1 · r

Column 1 of \(X\) is \((-1, -2, 1, 0)\) and \(r = (0, 1, 3, 3)\). What is (column 1) \(\cdot\, r\)?

\[\begin{aligned}&(-1)\cdot 0 + (-2)\cdot 1 + 1\cdot 3 + 0\cdot 3\\ &= 0 - 2 + 3 + 0 = 1\end{aligned}\]

The other two columns give 7 and 12, so \(X^\top r = (7, 1, 12)\) and \(2X^\top r = (14, 2, 24)\).

Show the other two columns \[\begin{aligned}&(1, 1, 1, 1)\cdot(0, 1, 3, 3)\\ &= 1\cdot 0 + 1\cdot 1 + 1\cdot 3 + 1\cdot 3\\ &= 0 + 1 + 3 + 3 = 7\end{aligned}\] \[\begin{aligned}&(1, 0, 3, 1)\cdot(0, 1, 3, 3)\\ &= 1\cdot 0 + 0\cdot 1 + 3\cdot 3 + 1\cdot 3\\ &= 0 + 0 + 9 + 3 = 12\end{aligned}\]
The penalty · note 6

Derivative of \(|\theta_j|\): its sign

\(|a|\) has slope \(+1\) when \(a > 0\) and \(-1\) when \(a \lt 0\), so its derivative is \(\mathrm{sign}(a)\). At 0 there is a corner and no derivative. That's why Q1.2 says "assume all entries of \(\theta\) are non-zero". Only \(|\theta_j|\) contains \(\theta_j\):

\[\frac{\partial}{\partial\theta_j}\,\lambda\big(|\theta_0| + |\theta_1| + |\theta_2|\big) = \lambda\,\mathrm{sign}(\theta_j)\]
Check · a sub-step of 2025-C Q1.3

The penalty's push

\(\theta = (1, -2, 3)\) and \(\lambda = 1\). What is \(\lambda\,\mathrm{sign}(\theta)\)?

The signs: \(\mathrm{sign}(1) = +1\), \(\mathrm{sign}(-2) = -1\), \(\mathrm{sign}(3) = +1\). So:

\[\lambda\,\mathrm{sign}(\theta) = 1\cdot(1, -1, 1) = (1, -1, 1)\]

Added to \(2X^\top r = (14, 2, 24)\): \((14 + 1,\ 2 + (-1),\ 24 + 1) = (15, 1, 25)\).

The official Q1.3 solution prints the middle entry as 0. That is a slip: \(2 + (-1) = 1\).

Put together

The whole gradient

The gradient of a sum is the sum of the gradients: the squared-error part (screen "4 of 4") plus the penalty part (the sign screen). \(\mathrm{sign}(\theta)\) is the vector of the signs of the entries.

\[\nabla J_\lambda(\theta) = 2X^\top(X\theta - y) + \lambda\,\mathrm{sign}(\theta)\]
