2025-C Q1.2: the gradient of the LASSO loss

\(J_\lambda\) is defined in the question's stem:

\[\begin{aligned}J_\lambda(\theta) = &\sum_{i=1}^{n}\Big(\theta_0 + \sum_{j=1}^{p}\theta_j x^{(i)}_j - y^{(i)}\Big)^2\\ &+ \lambda\big(|\theta_0| + \dots + |\theta_p|\big)\end{aligned}\]
See the whole stem (image)

We'll solve it in small moves. Each move is one line. Tap why? only if the line isn't obvious. Press Show next move when you're ready (or N).

1
Translate the question: the gradient is the vector of partial derivatives, one per knob. So find \(\dfrac{\partial J_\lambda}{\partial\theta_j}\) for one general knob \(j\).
why?

The picture. Imagine \(J\) as a landscape. Your position is the knob setting \(\theta\); the height at that position is the loss \(J(\theta)\). Training = finding the lowest point. You can't see the whole landscape, but where you stand you can feel which way the ground slopes. The gradient is that slope.

One knob. The partial derivative \(\partial J/\partial\theta_1\) answers: "if I turn only knob \(\theta_1\) up a tiny bit and hold the other knobs still, how fast does \(J\) change?" You compute it like an ordinary derivative, treating the other knobs as constants.

All knobs. The gradient stacks the partial derivatives into one vector:

\[\nabla J = \left(\frac{\partial J}{\partial\theta_0},\ \frac{\partial J}{\partial\theta_1},\ \dots,\ \frac{\partial J}{\partial\theta_p}\right)\]

It points uphill, so \(-\nabla J\) points downhill; gradient descent (Q1.3) walks that way. If we find entry \(j\) for a general \(j\), we have every entry.

2
Name the bracket: \(r_i = \theta^\top x^{(i)} - y^{(i)}\), so \(J_\lambda(\theta) = \sum_i r_i^2 + \lambda\big(|\theta_0| + \dots + |\theta_p|\big)\).
why?

The bracket is the residual. \(\theta_0 + \sum_j \theta_j x^{(i)}_j\) is the model's prediction for sample \(i\), and \(y^{(i)}\) is its true label. Prediction minus truth is the residual \(r_i\) (note 0).

Why \(\theta^\top x^{(i)}\). Write the bias as \(\theta_0\cdot 1\). Then the prediction is a dot product of the knobs \((\theta_0, \theta_1, \dots, \theta_p)\) with the sample's features with a 1 in front, \((1, x^{(i)}_1, \dots, x^{(i)}_p)\). That vector is row \(i\) of the data matrix \(X\) (note 1).

The two parts of \(J_\lambda\). \(\sum_i r_i^2\) is the squared error: squaring stops a \(+3\) and a \(-3\) from cancelling (note 2). The second part is the LASSO penalty, which makes large weights cost something. It includes \(\theta_0\) here (note 3).

Naming \(r_i\) keeps the next lines short.

3
Split into the two parts: \(\dfrac{\partial J_\lambda}{\partial\theta_j} = \dfrac{\partial}{\partial\theta_j}\sum_i r_i^2 \;+\; \dfrac{\partial}{\partial\theta_j}\lambda\big(|\theta_0| + \dots + |\theta_p|\big)\)
why?

The derivative of a sum is the sum of the derivatives. So we can handle the squared-error part (moves 4–6) and the penalty (move 7) separately, and add them at the end (move 8).

4
Derivative of one residual: \(\dfrac{\partial r_i}{\partial\theta_j} = x^{(i)}_j\) (with \(x^{(i)}_0 = 1\)).
why?

Write it out: \(r_i = \theta_0\cdot 1 + \theta_1 x^{(i)}_1 + \dots + \theta_p x^{(i)}_p - y^{(i)}\). Differentiate with respect to \(\theta_j\): only the term \(\theta_j x^{(i)}_j\) contains \(\theta_j\). Everything else is a constant with derivative 0. So the result is the number multiplying \(\theta_j\), which is \(x^{(i)}_j\).

For \(\theta_0\) the number multiplying it is the 1, so call it "feature 0": \(x^{(i)}_0 = 1\). That is the ones column of \(X\).

The official solutions quote this as "we've seen in class that \(\frac{\partial}{\partial w_j} r_i = x^{(i)}_j\)". You may do the same.

5
Chain rule on one sample: \(\dfrac{\partial}{\partial\theta_j} r_i^2 = 2r_i\cdot\dfrac{\partial r_i}{\partial\theta_j} = 2r_i\,x^{(i)}_j\)
why?

Sample \(i\) contributes \(r_i^2\): an outer function (squaring) of an inner function (\(r_i\), which depends on \(\theta_j\)). Chain rule = (outer derivative) \(\times\) (inner derivative). The outer derivative of \(u^2\) is \(2u\), so \(2r_i\). The inner derivative is move 4's \(x^{(i)}_j\).

6
Add over the samples: \(\dfrac{\partial}{\partial\theta_j}\sum_{i=1}^{n} r_i^2 = 2\sum_{i=1}^{n} x^{(i)}_j\big(\theta^\top x^{(i)} - y^{(i)}\big)\)
why?

The derivative of a sum is the sum of the derivatives, so add move 5 over \(i = 1, \dots, n\): \(\sum_i 2r_i x^{(i)}_j\). The 2 is the same in every term, so pull it out in front. Then write \(r_i\) back in full, as the official solution does.

7
The penalty: \(\dfrac{\partial}{\partial\theta_j}\lambda\big(|\theta_0| + \dots + |\theta_p|\big) = \lambda\,\mathrm{sign}(\theta_j)\)
why?

The absolute value has two straight pieces: \(|a| = a\) when \(a > 0\) (slope \(+1\)) and \(|a| = -a\) when \(a \lt 0\) (slope \(-1\)). So its derivative is the sign of \(a\):

\[\begin{aligned}\frac{d}{da}|a| &= \mathrm{sign}(a)\\ &= \begin{cases}+1 & a > 0\\ -1 & a \lt 0\end{cases}\end{aligned}\]

At \(a = 0\) the graph has a corner and there is no derivative. That is why the question says "you may assume that all entries of \(\theta\) are non-zero".

In \(\lambda(|\theta_0| + \dots + |\theta_p|)\) only the term \(|\theta_j|\) contains \(\theta_j\); the rest are constants. So the result is \(\lambda\,\mathrm{sign}(\theta_j)\). Note there is no factor 2 here (unlike ridge's \(\theta_j^2\)).

8
Add moves 6 and 7, the \(j\)-th partial derivative:
\[\begin{aligned}\frac{\partial J_\lambda}{\partial\theta_j} = &\;2\sum_{i=1}^{n} x^{(i)}_j\big(\theta^\top x^{(i)} - y^{(i)}\big)\\ &+ \lambda\,\mathrm{sign}(\theta_j)\end{aligned}\]
why?

Move 3 split \(J_\lambda\) into two parts; this is where they come back together. This line is exactly the first line of the official solution. The question asks for the whole gradient, though, so stack it over all \(j\) (move 9).

9
\(\sum_i x^{(i)}_j r_i\) = (column \(j\) of \(X\)) \(\cdot\, r\). So stacked over all \(j\), the sum becomes \(X^\top(X\theta - y)\) and the signs become the vector \(\mathrm{sign}(\theta)\).
why?

Write the sum out: \(\sum_i x^{(i)}_j r_i = x^{(1)}_j r_1 + x^{(2)}_j r_2 + \dots + x^{(n)}_j r_n\). The numbers \(x^{(1)}_j, \dots, x^{(n)}_j\) are feature \(j\) of every sample: exactly column \(j\) of \(X\). So the sum is the dot product (column \(j\) of \(X\)) \(\cdot\, r\).

\(X^\top\) (X transposed) is \(X\) with its columns turned into rows. So \(X^\top r\) computes exactly these dot products, one per column, all at once. And \(r = X\theta - y\) is the vector of all residuals (note 1).

\(\mathrm{sign}(\theta)\) is the vector \((\mathrm{sign}(\theta_0), \dots, \mathrm{sign}(\theta_p))\): the official solution calls it "the vector in \(\{-1, +1\}^{p+1}\)".

Trap: it is \(X^\top(X\theta - y)\), not \(X(X\theta - y)\). The gradient has one entry per knob, not per sample. Size check (2025-C): \(X^\top\) is \(3\times 4\), \(X\theta - y\) is \(4\times 1\), product \(3\times 1\).
10
The answer:
\[\nabla J_\lambda(\theta) = 2X^\top(X\theta - y) + \lambda\,\mathrm{sign}(\theta)\]
why?

Move 8 for every \(j\), written with move 9's vectors. "Do not use numeric values for \(X\) and \(y\)" means: answer with the symbols, not the table. That's what this is.

see it with 2025-C's numbers (used in Q1.3)

\(\theta = (1, -2, 3)\), \(\lambda = 1\), residuals \(r = X\theta - y = (0, 1, 3, 3)\) (note 1). Each entry of \(X^\top r\) is one column of \(X\) dotted with \(r\):

\[\begin{aligned}&(1, 1, 1, 1)\cdot(0, 1, 3, 3)\\ &= 1\cdot 0 + 1\cdot 1 + 1\cdot 3 + 1\cdot 3\\ &= 0 + 1 + 3 + 3 = 7\end{aligned}\] \[\begin{aligned}&(-1, -2, 1, 0)\cdot(0, 1, 3, 3)\\ &= (-1)\cdot 0 + (-2)\cdot 1 + 1\cdot 3 + 0\cdot 3\\ &= 0 - 2 + 3 + 0 = 1\end{aligned}\] \[\begin{aligned}&(1, 0, 3, 1)\cdot(0, 1, 3, 3)\\ &= 1\cdot 0 + 0\cdot 1 + 3\cdot 3 + 1\cdot 3\\ &= 0 + 0 + 9 + 3 = 12\end{aligned}\]

So \(2X^\top r = 2\cdot(7, 1, 12) = (14, 2, 24)\). The signs: \(\lambda\,\mathrm{sign}(\theta) = 1\cdot(1, -1, 1) = (1, -1, 1)\).

\[\begin{aligned}\nabla J_\lambda &= (14 + 1,\ 2 + (-1),\ 24 + 1)\\ &= (15, 1, 25)\end{aligned}\]

The official Q1.3 solution prints the middle entry as 0. That is a slip: \(2 + (-1) = 1\).
